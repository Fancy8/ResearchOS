## 已实施

- POST /projects、/projects/{id}/threads、/notes 对提供 Idempotency-Key 的请求
  使用事务回执，按空间、用户、操作和线索父课题隔离。并发同键一次创建、事件
  和初始修订；不同有效正文返回冲突。为兼容现有 API，不带键仍按原语义创建，
  因此不对无键客户端宣称安全重放。空/过长的已提供键失败关闭。
- 三个前端入口改为 ResearchCreateDialog。保存前持久记录原键/路径参数/正文；
  未确认时冻结输入。明确拒绝可修正原正文，保留键；权限/网络不明错误不自动换键。
  成功后只保存资源身份，不把原创建实体写入当前详情缓存，避免旧回执降级新版本。
- 创建目标与顶栏当前课题分开；线索恢复始终使用原 parentId。每个同源空间每种
  创建类型一条恢复记录，路径由固定类型与 UUID 生成，不存任意可执行地址。
- 记录包含提交的标题/背景/问题，属于本机科研草稿，**不是只含元数据**，也没有
  宣称加密。界面说明会保留在此浏览器，退出登录/账户删除按空间前缀清除。
  无法保存时不发送写请求，保留未提交输入；已确认创建但回执保存失败保留内存
  确认，读取可修复本机回执。刷新后仍未知时用原键确认。
- 原生创建窗口通过 Web Locks 持有该类型的编辑权到窗口关闭；有待处理请求时
  先等请求结束再释放，组件卸载会释放。写入还有同步 busy 守卫。此机制已实现，
  专门的多标签页竞争/释放用例尚未补齐，不能据其他模块测试外推已验收。
- 详情页用独立“创建确认回执”提示，详情或默认课题的后台读取失败不会撤销确认。
  默认课题后台读失败有缓存时保留页面。正常创建后打开确切新对象；线索入口也
  直接进入新线索详情。手动读取不会重新 POST。
- 本轮没有 ORM 或迁移变化。OpenAPI 新增三个可选 Header，已重新生成契约；
  路径/响应结构仍为 74 / 143，TypeScript DTO 没有变化。
