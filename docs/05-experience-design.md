# 页面与交互设计

依据 S1 第 6–9、14 节；本次提供功能线框和交互规则，不声称已制作可操作应用原型。

## 信息架构与页面职责

桌面布局：220px 左导航、56px 顶栏、可折叠 320–360px 上下文面板；阅读时主导航收为 64px。1366×768 下主要操作可见，内容区域滚动，避免底部操作被挡。移动端先保证基本浏览，PDF 精确摘录不作为移动端验收承诺。

| 页面 | 路由 | 首要动作与数据 | 空/失败状态 |
| --- | --- | --- | --- |
| P01 注册/登录 | /login | 登录、邀请注册、找回密码 | 统一认证失败，避免邮箱枚举 |
| P02 初次引导 | /onboarding | 研究领域、课题阶段、首个研究问题 | 偏好可跳过，逐步保存与恢复 |
| P03 科研桌面 | /dashboard | 当前课题、线索、任务、阶段排序 | 无课题引导；无任务不虚构数据 |
| P04 课题列表 | /projects | 新建、默认、筛选、归档 | 示例引导与真实数据分开 |
| P05 课题详情 | /projects/:projectId | 目标、阶段、线索、关联文献笔记 | 归档后可浏览/恢复，说明状态 |
| P06 线索列表 | /projects/:projectId/threads | 新建问题、筛选、状态 | 无线索给单一创建入口 |
| P07 线索详情 | /threads/:threadId | 问题→证据→假设→决策→任务 | 各分区独立加载/失败，不把失败显示为零 |
| P08 文献库 | /library | 上传、元数据编辑、复用、阅读状态 | 上传和解析状态分开，失败可重试 |
| P09 PDF 阅读器 | /papers/:paperId | 翻页、选择原文、创建证据 | 扫描件人工页码证据；签名到期续签 |
| P10 笔记列表 | /notes | 新建、筛选、恢复软删除笔记 | 明确空列表与无搜索结果 |
| P11 笔记编辑 | /notes/:noteId | 编写、引用、自动保存 | 待保存/保存中/已保存/失败/冲突 |
| P12 研究日志 | /activity | 课题/线索过滤、历史跳转 | 目标已删除显示历史快照，不假装跳转成功 |
| P13 科研任务 | /tasks | 新建、执行、完成、重开 | 保存失败保留原状态和输入 |
| P14 科研画像 | /profile/research | 显式背景、阅读、布局偏好 | 关闭个性化可用；阶段设置留在课题 |
| P15 全局搜索 | /search | 关键词、对象类型、结果跳转 | 清楚告知 P0 搜索标题与笔记，不搜整篇 PDF |
| P16 设置与数据 | /settings/data | 导出、下载、资料影响预览、账户删除 | 导出过期可重新发起；删除明确影响范围 |

P07/P09 是优先设计对象；假设、决策以 P07 分区/侧面板打开，历史详情不再增加无定义的全局导航入口。任务全局列表支持课题筛选；从决策产生任务默认绑定该课题/线索/修订，不能在表单里静默改成其他课题。

## 研究线索详情线框

```text
┌ 主导航 ┬ 课题选择器 / 搜索 / 账号 ─────────────────────────────────┐
│        │ 课题路径 > 研究线索                                     │
│ 桌面   │ 研究问题标题  [进行中]   [编辑问题] [查看问题历史]        │
│ 课题   ├────────────────────────────────┬──────────────────────┤
│ 文献   │ 问题及背景                      │ 关联论文 / 笔记       │
│ 笔记   │ 证据 [添加/从文献摘录]          │ 最近活动             │
│ 日志   │ 原文 + 用户解释 + 来源精度      │                      │
│ 任务   │ 假设 [提出假设]                 │                      │
│ 设置   │ 支持 / 反面 / 背景 / 不确定     │                      │
│        │ 决策 [记录判断] [版本历史]      │                      │
│        │ 下一步任务 [创建] [完成]        │                      │
└────────┴────────────────────────────────┴──────────────────────┘
```

每条证据显示论文、具体文件版本、页码、原文和用户解释，精确定位/页码定位/来源待处理状态显式可见。假设状态与证据关系是两个控件；“3 条支持”不能自动呈现为“假设成立”。决策保存必须有理由，历史视图展示该版本的依据快照，另设“查看当前对象”入口。

新增内容完成后留在当前上下文，并只刷新相关分区。问题编辑显示“将记录新的问题版本”，用户仍能查看过去的提问表述。分区默认有限条目，“查看更多”调用独立分页，避免打开线索即加载全部论文和笔记正文。

## PDF 阅读与证据线框

```text
┌ 返回文献库 | 论文标题 [文件 v2] | 页码 / 缩放 / 阅读状态 ─────────┐
│ 缩略图    │ PDF 页面 + 文本层                 │ 证据面板          │
│ 可隐藏    │                                   │ 原文摘录          │
│           │ 选择原文 → [创建证据]             │ 来源：v2 / 第4页  │
│           │                                   │ 研究线索（必选）  │
│           │                                   │ 我的解释          │
│           │                                   │ 假设关系（可选）  │
│           │                                   │ [保存证据]        │
└───────────┴───────────────────────────────────┴───────────────────┘
```

从证据打开阅读器携带 `fileId/page/evidenceId`，强制获取它引用的版本。文件为历史版本时顶部明确提示，可另行打开当前版本；不能先打开 current 再尝试定位旧证据。服务器校验 located 后高亮，page_only 只滚动页码且显示状态。跨页选择按页保存矩形，不保留 DOM 临时节点。

PDF.js 的 viewport 变换包含缩放、旋转和 PDF/Canvas 坐标差异，因此持久坐标须先转换到统一未旋转空间，再归一化；缩放后再从该坐标变换回来。[PDF.js 官方示例](https://github.com/mozilla/pdf.js/blob/master/docs/contents/examples/index.md)

多栏、断行连字符、重复段落、旋转、不同裁剪框、跨页、多缩放比例、历史文件版本列入 S0 技术验证。选中文本优先保留用户看到的摘录；服务端规范化只用于匹配，不悄悄改写原文。扫描件显示“可阅读，文本不可直接选择”，允许用户输入摘录并保存 page_only，无法验证为论文原文时给出“人工录入摘录”标签。

创建证据默认使用当前课题最近选择的合法线索；用户仍须明确确认。未与线索关联的论文，在保存时由服务端事务建立两层合法文献关系，减少额外操作。保存失败保留输入和源选择，同键重试不新增第二份证据。

## 保存、冲突与反馈

| 场景 | 反馈设计 | 状态依据 |
| --- | --- | --- |
| 笔记连续输入 | 输入停止建议 1 秒后提交，保存中可继续编辑 | 用本地编辑序号关联每次请求；旧响应不得覆盖新草稿 |
| 笔记已保存 | 显示服务器 last_saved_at | 只有服务器确认后才显示已保存 |
| 断网/请求失败 | 显示未保存、本地草稿与重试 | 浏览器草稿按账号/空间/note 隔离，退出清理 |
| 两标签页冲突 | 显示本地与远端差异，允许复制、重新加载或人工合并 | 409 + current_version；不自动覆盖 |
| 草稿恢复 | 列出服务器版本和草稿时间，让用户选择恢复 | 草稿只是本机暂存，不承诺等同备份 |
| 任务完成 | 服务确认后状态变更，支持明确重开 | completed_at 与状态同事务 |
| 上传重复 | 显示相同摘要/DOI 的当前空间文献候选 | 用户选择复用或保留，不自动删除/合并 |
| 删除/移除 | 区分“仅移除关联”与“删除原对象”；展示引用依赖 | 后端实时影响预览；受引用文件默认阻止普通删除 |

浏览器暂存私密草稿有本机暴露风险：最小化保留、设定 TTL、提供清理入口，登出/切换账号清空；不承诺无痕或浏览器被清空时仍可恢复。正常关闭页面前有待保存提示，不靠 beforeunload 假定最后一次请求成功。

## 个性化、可访问性与设计验收

首页优先级为“用户固定模块 → 当前课题阶段排序 → 默认模块”。布局配置按课题隔离，关闭个性化恢复固定默认排序，不修改科研事实。阶段对应：调研优先问题与阅读；设计优先假设与验证计划；实验优先假设与实验相关任务；写作优先结论依据与写作行动；自定义按手工顺序。

设计系统统一字体、间距、颜色 token、表单、标签、列表、对话框和 toast。颜色不单独表达状态；支持键盘操作、焦点可见、对话框焦点回收、中文表单标签、可读错误反馈。PDF 选择快捷方式提供可见按钮替代。

上线设计验收覆盖：1366×768 与 1920×1080；桌面 Chrome/Edge/Safari 当前稳定版；中文长标题、英文长词、空列表、慢请求、失败重试、弹窗与右侧面板；缩放到 200% 时关键操作可到达。Safari 与不同浏览器版本需真实设备或浏览器执行，不能只在开发者工具模拟分辨率。
