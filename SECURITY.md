# Security policy

ResearchOS is an early alpha with no production-supported release or independent security certification.

Please use this repository's **Security → Report a vulnerability** option when available for a private report. If that option is unavailable, open an issue requesting a private reporting channel, without vulnerability details or sensitive attachments. Never post credentials, private PDFs, session cookies, user records, or exploit payloads in a public issue.

Include affected revision, environment, impact, and a minimal synthetic reproduction through a private channel. There is no promised response SLA or bug bounty. Maintainers must review authorization, immutable history, export/deletion behavior, dependencies, and deployment isolation before release. Local loopback bootstrap settings are not production configuration.
